
Okno dolaczenia do serwera

- {"type":"connecting_with_server","nick":"Alicja"} - klient -> serwer - proba polaczenia z serwerem
- {"type": "nick_accepted", "session_id": 12345} - serwer -> klient - udalo sie uzyskac polaczenie
- {"type": "nick_rejected", "reason": "Ten nick jest zajęty"} - serwer -> klient - gdy nick jest juz zajety

- {"type": "network_error", "reason": "Brak połączenia."} - serwer -> klient - jesli nie udało się połaczyc z serwerem, to jest 
  obsluzone w kliencie kiedy nie uda sie nawiazac polaczenia, wiec nie musisz tego obslugiwac, ale wolalam wypisac zeby sie nie pogubic
- {"type": "didnt_send", "reason": "Nie udało się wysłać wiadomości."} - jest polaczenie z serwerem, ale nie udalo sie wyslac, to samo co poprzednie
    nie musisz tego obslugiwac


Wszystkie wiadomości wysyłane przez serwer i klienta muszą kończyć się znakiem nowej linii (\n) np. {"type": "nazwa_komunikatu", "pole1": "wartosc"} + \n

2.wysylam do serwera {"type": "REQUEST_GAME_INFO"} 
3 odpowiedz od serwera to ,...
"IN_ROUND" - gra trwa rozpoczala sie runda
{
    "type": "GAME_STATUS",
    "game_status": "IN_ROUND",                 
    "current_round": 1,                     
}
"LOBBY" - gdy nie ma dwóch graczy, lub gdy jest ich dwójka i czekamy minute na innych aby rozpoczac
{
    "type": "GAME_STATUS",
    "game_status": "LOBBY",                
    "waiting_status": "COUNTDOWN", // COUNTDOWN (odliczanie) lub IDLE (bez odliczania czyli czekamy na dwoch graczy)
    "time_remaining": 45           // Czas pozostały do startu/anulowania (w sekundach)
}
na pewno serwer musi komunikowac ze skonczylo sie odliczanie
"GAME_OVER" - gra sie zakonczyla
{
    "type": "GAME_STATUS",
    "game_status": "GAME_OVER",                                
}
4. w zaleznosci od stanu pokazuje sie konkretne okno 
- in round
dwa przyciski :
    1. dolacz do nastepnej rundy - klient -> serwer {"type": "WANT_TO_PLAY_IN_NEXT_ROUND"}
                               
    2. dolacz od nastepnej gry - klient -> serwer {"type": "WANT_TO_QUEUE"} 

    - lobby - zmiana jednak nie ma przycisku
    klient po wejsciu do lobby wysyla klient -> serwer {"type": "WANT_TO_PLAY"} 
    opcja a) tutaj serwer musi informowac klienta o zmianie stanu np kiedy na poczatku jest stan 
        "type": "GAME_STATUS",
        "game_status": "LOBBY",                
        "waiting_status": "IDLE" (czyli czekanie na drugiegio gracza)
    gdy dołaczy ten drugi, serwer musi wyslac do klienta 
        "type": "GAME_STATUS",
        "game_status": "LOBBY",                
        "waiting_status": "COUNTDOWN",
        "time_remaining": np 45 

    opcja b) gracz w chodzi w czasie countdown 

    - game GAME_OVER
    po wyswietleniu wynikow przechodzi do okna lobby

5. Odnoscie okna gry, kiedy jest min dwoch graczy i skonczy sie oczekiwanie na reszte serwer wysyla wiadomosc
    "type": "ROUND_START",
    "current_round": 1,
    "letter": "B",
    "current_points": 0, //serwer musi w tym miejscu odsylac ile dany gracz ma punktow sumarycznie
    "players_count": 2 
    opcja a) gdy gracz wpisze odpowiedzi i jest pierwsza osoba ktora konczy do serwera wysylana jest wiadomosc:
        {'type': 'ROUND_END_ANSWERS', 'answers': {'państwo': 'lalala', 'miasto': 'dd', 'roślina': 'dd', 'zwierzę': 'dd', 'rzecz': 'dd'}, 'is_first': True}
        gdy wartosc is_first = true -> serwer wysyla pozostalym graczom wiadomosc:
            "type": "TIME_WARNING",
            "time_left": 10 //to oznacza ze reszta ma 10s na odpowiedz
    opcja b) z flaga is_first = false - raczej nie bedzie wymagac zadnej odpowiedzi

    - WANT_TO_QUEUE, 
7. Kiedy wszyscy gracze wysla odpowiedzi w piatej rundzie serwer wysyla wszystkim graczom wiadomosc, wtedy widza okno wynikow

    {
    "type": "FINAL_SCORES",
    "your_place": 1, //dla konkretnego gracza
    "total_points": 150, //dla konkretnego gracza
    "top_3": [
        {"nick": "Ania", "points": 150}, //to sa slowniki 
        {"nick": "Tomek", "points": 120},
        {"nick": "Gracz3", "points": 90}
    ]
    }

    w oknie wynikow jest odliczanie 20 sekund (wyniki sa wyswietlane przez 20 sekund )po ktorych jest przeniesienie do okna lobby i zadanie request_game_info.\
    W czasie gdy wyswietlane sa wyniki czyli od wiadomosci final_scores przez te 20 sekund stan gry to game_over i gdy ktos dolaczy w tym czasie powinien dostac
    wiadomosc {
        "type": "GAME_STATUS",
        "game_status": "GAME_OVER",                                
        }

        tutaj ogolnie nie jestem przekonana jak to rozwiazac bo mysle ze czas moze sie rozjezdzac ogolnie po tych 20 sekundach powinna powstac nowa gra tak aby ktos
        kto pozostal w grze (po tych 20 sekundach) dostal stan gry lobby
